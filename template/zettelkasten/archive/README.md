# Historical Evidence

This directory is excluded from ordinary AI reading, task discovery, content search and routine validation. See [[knowledge-lifecycle]].

Read an exact snapshot only when the task needs historical evidence or requests a full audit. Preserve snapshots in Git. They are evidence of the state at archival time, not current instructions or canonical task state.

Stable source summaries retain the authoritative identity, state, relationships, archive path and checksum. Retrieve history through those references. Never load all historical bodies merely to choose a current task or procedure.
